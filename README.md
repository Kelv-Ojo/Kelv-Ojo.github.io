# Kelvin Ojogbede | Data Analyst Portfolio

[Visit the portfolio](https://kelv-ojo.github.io/)

A responsive portfolio featuring hotel bookings, customer churn, UK energy consumption and sales reporting. Built with HTML, CSS and JavaScript, with project filters, accessible case-study dialogs and direct links to reproducible source analysis.

## Run locally

Run `python3 -m http.server 8000` in this directory, then open http://localhost:8000.

## Content

Each project links to its dataset context, methods, checks and limitations in its source repository. Charts are generated from the documented analysis; no live client results are implied.
