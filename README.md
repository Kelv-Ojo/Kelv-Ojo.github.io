# Kelvin Ojogbede | Data Analyst Portfolio

[Visit the portfolio](https://kelv-ojo.github.io/)

A responsive portfolio featuring hotel bookings, customer churn, UK energy consumption and sales reporting. Built with HTML, CSS and JavaScript, with project filters, accessible case-study dialogs and direct links to reproducible source analysis.

## Run locally

Run `python3 -m http.server 8000` in this directory, then open http://localhost:8000.

## Content

Each project links to its dataset context, methods, checks and limitations in its source repository. Charts are generated from the documented analysis; no live client results are implied.

## Problem, implementation and evidence

The site helps a recruiter move from a project question to its methods, findings and source repository. HTML, CSS and JavaScript provide responsive pages, filters, accessible dialogs and visual interactions. Development used disclosed AI assistance; the repository is a work sample to inspect and explain, not evidence of a commercial software delivery.

This is a static website, with no application database. Dataset sources, methodology, analytical findings and limitations live in the linked project repositories and case-study folders. The site itself has no model score or business-impact result. To view its visuals, run the local server above or visit the public site; do not substitute generated mockups for project screenshots.

**Skills demonstrated:** communicating analysis, organising evidence, HTML/CSS/JavaScript integration, responsive layout and documenting local setup. The original angel, skull, star, skills and 3D elements are preserved. Underlying analyses have separate validation; rendering a chart does not validate its methodology.
